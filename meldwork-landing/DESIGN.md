# multiwork 官网视觉设计

首屏左侧介绍 Windows 桌面应用，右侧展示可切换成员的会话用量。宽度不超过 720 像素时，面板紧随下载入口排列。向下滚动可查看桌面截图、协作方式和安装步骤。

- **页面底色**使用暖白纸色与低对比点阵；深色模式使用松绿色背景。色值集中在 `styles.css` 的根变量中。
- **用量面板**使用深绿底色。薄荷绿对应输入，浅黄对应输出，两种数值都有文字图例。切换 Agent 时沿用相同刻度。
- **排版**以系统无衬线字体呈现正文，以等宽数字呈现 token 计数。图表与选项控件始终标示示例性质。
- **交互**保留可见的键盘焦点，协作方式以原生折叠面板呈现。减少动态效果的系统设置会关闭平滑滚动。
