# multiwork 官网视觉设计

首屏左侧介绍 Windows 桌面应用，右侧展示可切换成员的会话用量。宽度不超过 760 像素时，面板紧随下载入口排列。向下滚动可查看桌面截图、协作方式和安装步骤。

- **页面底色**使用深蓝色，首屏以青紫色动态流线连接两栏。浅色模式使用低饱和的青灰与淡紫色。流线在离开视口或页面隐藏后暂停，减少动态效果时保持静态。配色集中在 `studio.css`。
- **用量面板**使用半透明深蓝底色。青色对应输入，淡紫色对应输出，两种数值都有文字图例。切换 Agent 时沿用相同刻度。
- **排版**以系统无衬线字体呈现正文，以等宽数字呈现 token 计数。图表与选项控件始终标示示例性质。
- **交互**保留可见的键盘焦点，协作演示支持自动播放、手动逐步查看和完整记录，FAQ 使用折叠面板。减少动态效果的系统设置会关闭平滑滚动。
